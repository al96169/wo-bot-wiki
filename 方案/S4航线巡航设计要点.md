# S4 航线巡航：从"扫地机器人"到"目标导向"

> 背景：S3-lite（视觉避障）+ V3（云台扫视）已经让机器人"能动、能绕"，
> 但这仍是**反应式**行为 —— 与环境的关系只有"前方有没有障碍"。
> 扫地机器人也一样。**质变的分界是：知道自己在哪、要去哪，并能纠正偏差。**

## 1. 缺什么（不是避障，是定位与航线）

| 能力 | 现状 | 说明 |
|---|---|---|
| 障碍感知 | ✅ 有（V1 TTC + V3 方位图） | 已够用 |
| **航向** | ✅ 有（IMU 陀螺） | 短期可靠 |
| **位移/定位** | ❌ **缺**（里程计未标定，且会漂移） | **当前最大瓶颈** |
| **航线表示** | ❌ 无 | 需要航点/拓扑路线 |
| **航向控制** | ❌ 无 | 需要"沿航线走"的闭环控制 |
| **重定位/纠偏** | ❌ 无 | 否则走两趟就偏掉 |

## 2. 两个可选范式（工作量差一个数量级）

### 范式 A：示教—重现（teach & repeat）**← 推荐先做**
1. **示教**：手动遥控带它走一遍目标路线，同时记录 `(航向, 位移增量, 视觉关键帧)`
2. **重现**：按记录的航点序列自动行驶，用
   - 陀螺维持航向
   - 里程计推算行进距离
   - **视觉关键帧重定位**（识别示教时记录的地标）做周期性纠偏

- 优点：不需要地图、不需要 SLAM；**行为是目标导向的、可重复的**，明显超越扫地机器人
- 缺点：路线由人教；环境大变（家具挪动）需要重新示教
- 依赖：**里程计标定**（必须先做，约 1 小时）

### 范式 B：地图 + 目标点（真 SLAM）
栅格/拓扑地图 + 全局路径规划 + 闭环定位（视觉 SLAM 或激光）。
- 优点：通用、能自己规划新路线
- 缺点：**本平台现实上做不到** —— 无激光雷达、无 CUDA/AI 运行时（见方案 §3.2），
  纯视觉 SLAM 在 4GB Jetson Nano 上跑不动。属于**换硬件**级别的工作。

## 3. 诚实的天花板（必须让用户知道）

1. **纯里程计必然漂移**：麦克纳姆轮打滑 + 陀螺零偏。走 10 米可能偏几十厘米。
   → 所以必须有**视觉重定位锚点**，否则"走两趟就不一样了"。
2. **视觉重定位在弱纹理/光照变化下不可靠**（走廊白墙、夜晚）→ 需要沿途放**人工标记**
   （AprilTag/二维码），这是低成本、高可靠的务实做法。
3. **动态障碍**（人走动）只能靠反应式层（V1/V3）处理 —— 规划层回避不了未知动态物。
4. 因此 S4 的正确形态是 **"弱定位 + 强反应"**：
   规划层给方向与航点，反应层随时可覆盖（避障优先），
   **不代表可以放开安全层**。

## 4. 建议的落地顺序

1. **里程计标定**（1 小时，阻塞项）：直行 1m / 原地转 90° 实测 `counts_per_meter`
2. **航向控制**：给定目标航向 → PID 转到位（先用陀螺，闭环简单、见效快）
3. **航点序列执行**：`走这段距离 → 转到该航向 → 再走…`（示教数据即航点）
4. **示教录制**：手动走一遍 → 存航点文件
5. **视觉重定位**（可选增强）：沿途标记 + 关键帧匹配纠偏
6. 与反应层/PV3 协同：航线给出意图，避障可否决

## 5. 验收（区别于扫地机器人的判据）

- 沿 4~6 个航点的闭合路线走一圈，**回到起点误差 < 30cm**（有标记纠偏时）
- 中途被人/箱子挡住 → 绕开或停下等待，**恢复后继续沿原航线**（不是转向乱走）
- 同一路线连走 3 次，轨迹一致性（同一位置偏差 < 20cm）
